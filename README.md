# 📚 Book Catalog & Order Service

A full-stack book catalog and ordering application built with Angular and Spring Boot.

## 📂 Repositories

### 🖥️ Frontend — Angular

The frontend application built with Angular.

👉 [View Frontend Repository](https://github.com/momen882001/Angular_BookCatalogOrderService)

### ⚙️ Backend — Spring Boot

The backend REST API built with Java and Spring Boot.

👉 [View Backend Repository](https://github.com/momen882001/Java_BookCatalogOrderService)

## 🛠️ Tech Stack

**Frontend**
- Angular
- TypeScript
- HTML

**Backend**

- PostgreSQL
- Liquibase
